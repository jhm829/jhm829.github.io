프로젝트 관리

프로젝트를 추가하고 설명, GitHub 링크, 파일을 직접 등록할 수 있습니다.

① GitHub 연결

저장할 때만 GitHub 권한이 필요합니다. 발급한 Fine-grained Personal Access Token을 입력해 주세요. 토큰은 이 브라우저 탭의 메모리에서만 사용하며 저장하지 않습니다.

연결 대상: jhm829/jhm829.github.io · 권한: Contents Read and write · 토큰을 채팅이나 다른 사람에게 공유하지 마세요.

관리 페이지 주소는 공개되어도 토큰을 모르면 수정할 수 없습니다. 다만 인터넷에 공개된 웹페이지에서 토큰을 입력하는 방식에는 보안 위험이 있으므로, 본인 기기에서만 사용하고 만료 기간이 짧은 토큰을 권장합니다.

② 프로젝트 등록 / 수정

내용을 작성한 뒤 GitHub에 저장을 누르면 공개 사이트에도 반영됩니다. 이미지나 파일을 선택했다면 함께 업로드합니다.

최대 5MB/파일, 여러 개 선택 가능. 업로드하면 누구나 파일을 열거나 다운로드할 수 있습니다.

③ 등록된 프로젝트 (0)

수정 버튼으로 기존 정보를 변경할 수 있습니다. 삭제하면 카드만 목록에서 빠지고 기존에 올린 첨부파일은 저장소에 남습니다.

처음 사용하나요?

  1. 먼저 GitHub에 jhm829.github.io라는 Public 저장소를 만들고 사이트 파일들을 업로드하세요.
  2. Fine-grained Personal Access Token 발급 페이지에서 소유자를 jhm829로 선택하고, 대상 저장소 하나만 지정하세요.
  3. Repository permissions → Contents: Read and write를 선택하고 토큰을 생성하세요.
  4. 위에 토큰을 입력하고 연결한 뒤 프로젝트 제목, 설명, 주소와 파일을 작성하여 저장하세요.
  5. 사이트 배포 후 jhm829.github.io에서 프로젝트 카드가 보이는지 확인하세요.

이 관리 페이지는 별도의 계정 로그인 서버가 아닌 GitHub REST API를 사용합니다. 토큰은 브라우저에서 GitHub로 전송되며 GitHub의 권한 검사에 따라 저장됩니다. 공용 컴퓨터에서는 사용하지 마세요.
